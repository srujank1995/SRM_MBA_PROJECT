Project Overview

Understanding the problem, data, and approach

Problem Statement

Retail and e-commerce companies struggle to accurately predict product demand across different geographies, leading to overstocking, stockouts, and poor supply chain efficiency. This project builds an AI-driven forecasting system to address this challenge using historical transactional data.

Dataset
  • Source: UCI Online Retail Dataset
  • 541,909 transactions from a UK-based e-commerce retailer
  • Covers 38 countries across Europe, Asia, and the Americas
  • Date range: December 2010 – December 2011
  • Key features: Country, Quantity, UnitPrice, InvoiceDate
Objectives
  1. Analyse historical demand patterns by country
  2. Build and compare multiple regression ML models
  3. Select the best-performing model based on R² score
  4. Deploy a web application for real-time demand prediction
  5. Support business decisions through data-driven insights
