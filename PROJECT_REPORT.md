
# PROJECT REPORT

## Title
AI-Based Product Demand Prediction for E-Commerce Platforms

## Objective
The objective of this project is to predict product demand in e-commerce platforms using Artificial Intelligence and Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Random Forest Algorithm

## Methodology
1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Machine Learning Model Training
5. Prediction and Evaluation
6. Dashboard Development

## Machine Learning Algorithm
Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- R² Score

## Conclusion
The project demonstrates how AI and Data Science can be used for demand forecasting in e-commerce businesses. Accurate demand prediction helps businesses improve inventory management and customer satisfaction.
